# 01 · 插件功能总览

> 范围：`CodeLocatorPlugin` 模块在 IDE（IntelliJ IDEA / Android Studio）侧暴露给用户的全部功能。
> 取自 `src/main/resources/META-INF/plugin.xml`、`src/main/java/com/bytedance/tools/codelocator/panels/CodeLocatorWindow.kt:453-584` 与各 Action 类。

## 1. 入口形态

CodeLocator 在 IDE 中有四类入口：

| 入口类型 | 注册位置 | 说明 |
|----------|---------|------|
| **工具窗口** (`toolWindow`) | `plugin.xml:79-83`，`factoryClass = CodeLocatorWindowFactory` | 右侧停靠的 "CodeLocator" 工具窗，是绝大多数功能的容器 |
| **顶层 Action** | `plugin.xml:87-113` | `Install Apk`（Project 视图右键 + `⇧⌥I` 快捷键）、`Search Code`（编辑器右键） |
| **工具窗口工具栏 Action** | `CodeLocatorWindow.kt:createDefaultActionGroup()` | 工具窗口顶部一排按钮，全部通过 `ActionManager.createActionToolbar` 动态注册 |
| **右键弹出菜单** | `CodeLocatorWindow.kt:showPop()` 等 | 在 View 树/截图区点击右键弹出 |

另外还注册了：

- **`fileType` + `fileEditorProvider`**：把 `.codeLocator` 后缀文件注册为可在 IDE 内直接打开的文件类型（`plugin.xml:66-72`，`com.bytedance.tools.codelocator.fileeditor.*`，本仓库新增功能）。
- **`postStartupActivity`**：`CodeLocatorStartupActivity`、`CodeLocatorApplicationInitializedListener`（项目启动时检查更新、初始化目录等）。
- **`projectListeners`**：`CodeLocatorProjectManagerListener`（项目关闭时清理设备缓存）。

## 2. 顶层 Action（菜单/快捷键）

| Action ID | 类 | 入口 | 触发 | 功能简介 |
|-----------|----|------|------|---------|
| `codelocator.installapk` | `InstallApkMenuAction` | `ProjectViewPopupMenu` | 在 Project 视图右键选中 APK | 把当前选中文件作为 APK 安装到设备 |
| `codelocator.installprojectnewapk` | `InstallApkAction` | 快捷键 `⇧⌥I` | 全局快捷键 | 自动找到工程下最新的 APK 并安装 |
| `codelocator.JumpToFileGitUrlAction` | `SearchInWebAction` | `EditorPopupMenu` | 编辑器右键 | 在浏览器中以 Git URL 形式打开当前文件位置 |

## 3. 工具窗口工具栏 Action（典型布局，按 `createDefaultActionGroup` 顺序）

`CodeLocatorWindow.kt:453-584` 决定工具栏图标顺序与可见性。下表去掉了仅在 "Window 模式"（即打开历史 `.codeLocator` 文件时）才出现的差异，标记 `[W]` 表示在窗口模式下也可见，`[L]` 表示仅在主工具窗（live mode）可见。

| 按钮（图标提示） | Action 类 | 是否依赖 IDE 工程 | 备注 |
|------------------|-----------|-------------------|------|
| 抓取（Grab） `[L]` | `GrabViewAction` | 否（仅需 ADB） | 触发一次完整抓取流程 |

| 编辑 View `[L]` | `EditViewAction` | 否 | 弹 `EditViewDialog` 改 visibility/text/margin 等 |

| 报错跳转 | `ReportJumpWrongAction` | 否 | 弹出 `FixJumpErrorDialog`，上报跳转规则错误并下发到设备配置 |
| 安装 APK `[L]` | `InstallApkAction` | 是 | 同上文菜单 Action |

## 6. 工具箱（`ToolsDialog`）的 9 个小工具

`tools/BaseTool.kt`（`ToolsDialog.kt:76-89`）：

| Tool | ADB 实现 | 说明 |
|------|---------|------|
| `LayoutTool` | `setprop debug.layout true/false` + 广播 `ACTION_USE_TOOLS_INFO` | 打开/关闭显示布局边界 |

## 7. 右键 / 上下文菜单（节选）

`CodeLocatorWindow.showPop()` 根据当前选中是 View / Activity / Fragment / File 弹出不同 Action 组合。常见条目：

- `Copy Image (View/All/Foreground/Background)` ← `CopyImageAction`
- `Copy View Link` ← `CopyViewLinkAction`（本仓库新增，生成 `codelocator://view?file=...&path=...&memAddr=...&class=...&id=...&xml=...`，详见 `action/CopyViewLinkAction.kt:41-57`）
- `Copy 信息` ← `CopyInfoAction`
- `Get View Data` / `Get View Class Info` / `Get Intent Data`
- `Finish Activity`
- `Invoke Method`
- `Mark View` / `Mark View Chain` / `Clear Mark` / `Fold Sibling`
- `Jump Parent View`
- `Add Extra Field`
- `Top Item`
- `Schema 转二维码` ← `SchemaToQRAction`
- `Draw Attr`

## 8. 启动与生命周期

- `CodeLocatorApplicationInitializedListener.kt`：`postStartupActivity`，应用初始化时执行。
- `CodeLocatorStartupActivity.java`：每个工程启动时执行，做：FileUtils.init / 更新检查 / `DeviceManager.initAdbPath(project)` 等。
- `CodeLocatorProjectManagerListener.java`：工程关闭时清理 `DeviceManager.sProjectSelectDevice` 等缓存。

## 9. 速查清单

按 "用户最常说的话" 反推：

| 用户需求 | 路径 |
|---------|------|
| 抓一张当前界面 | 工具栏 `Grab` 按钮（`GrabViewAction`）|
| 抓但先停动画 | 工具栏 `Grab+StopAnim` 按钮 |
| 看历史抓取 | 工具栏 `History` 按钮（弹 `ShowHistoryDialog`）|
| 把当前抓取另存为文件 | 工具栏 `Save` 按钮（`SaveWindowAction`）|
| 安装 APK | 快捷键 `⇧⌥I` 或工具栏 Install / Project 右键 Install Apk |
| 改 View 的可见性 / 文本 | 选中 View → 工具栏 EditView |
| 跳到 View 对应代码 | 选中 View → 工具栏 Find View / Find OnClick / Find XML 等 |
| 改 HTTP 代理 / 布局边界 | 工具栏 Tools 工具箱 |
| 发 Schema | 工具栏 Tools → Send Schema |
| 跨进程剪贴板 | 工具箱 → Clipboard（需先装 helper APK） |
| 反馈日志 | 工具栏 Feedback |

> 详细的 Action ↔ 代码位置 ↔ "可否纯外部驱动" 对应表见 **07-IDE 端 Action 与扩展点清单.md** 与 **08-反向操作可行性矩阵.md**。
